# 独立评审记录

这里保存四轮独立评审的**人类可读**部分：结论、问题清单、证据截图。每轮一个目录，按日期命名。

|---|---|---|
| [2026-10-10-independent](2026-10-10-independent/) | v1.4（218 页） | 内容、可读性、工作流三条线的首轮独立评审；11 张原页截图 |

每轮目录里：

- `README.md`：当轮的基线与结论；
- `CLOSURE.md`：问题是怎么被关掉的（首两轮有）；
- `01-content.md`、`02-ui-reading.md`、`03-workflow.md`：内容、阅读体验、工作流三条分线报告；
- `evidence/`：直接能看的页面截图，配 `README.md` 说明拍的是哪一页、为什么拍。

## 关于机器读数

这些评审当时还留下了 JSON 索引、`checks/*.txt` 与复算脚本（`recheck_*.py`）。
2026 年做「以人为本」改造时，它们被移出仓库：**记录里留给人的部分保留，机器部分不再随仓库携带**。
需要时可以用 `check/` 下的检查器重跑复现（见顶层 README 的「质量检查」），
旧版本仍可从 git 历史取回。
