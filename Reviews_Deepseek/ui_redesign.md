# t8 — 视觉重设计样式原型：设计论点、新旧对比、迁移方案

- 原型文件：`src/style_v2_preview.tex`（独立可编译，**未触及**原稿的任何 tex 文件）
- 编译产物：`src/style_v2_preview.pdf`（7 页）→ 渲染 PNG 在 `Reviews_Deepseek/preview/`
- 原稿（只读参照）：`src/plasma_physics_textbook_v2.tex`、`src/ch*_supplement.tex`
- 编译实测：`Missing character = 0`，`Overfull \hbox = 0`，7 页 A4

---

## 0. 一句话设计论点

> **把「9 个高饱和色相」换成「一条等距明度阶梯 + 三重非颜色冗余编码」，
> 让语义在彩色屏、黑白打印、色觉障碍三种条件下都可分辨；
> 层级改由「尺幅 + 色带 + 缩进」承担，而不是靠颜色堆叠。**

这不是换色板，而是把**信息的承载方式**从颜色转移到形状与尺幅。
下面每一节都给出可验证的数值，而非审美断言。

---

## 1. 数值化诊断：旧样式到底哪里坏了

用 NTSC 灰度亮度 $Y=0.299R+0.587G+0.114B$ 量化原稿 9 色语义板：

| 指标 | 旧色板 | 新色板 | 变化 |
|---|---|---|---|
| 灰度值范围 | 65 – 170 | 45 – 130 | — |
| 相邻灰度**最小**间隔 | **1.5**（defgreen 93 vs historybrown 94） | **12.0** | **×8** |
| 相邻灰度**平均**间隔 | 13.1 | 12.2 | 更均匀 |
| 红绿色盲下 $d<45$ 的色对 | 4 | 4 | **未改善** |
| 对白 WCAG 对比度最低值 | **2.04:1**（warnyellow） | 3.13:1（提示） | 改善但仍 <4.5 |

复现脚本：`reviews_tmp/palette.py`（色板搜索）、`reviews_tmp/validate_palette.py`（校验）。

### 1.1 关键读数解读

旧色板的问题**不是**「颜色不够多」，而是「颜色全挤在同一个明度带」。
`defgreen`(46,125,50) 与 `historybrown`(121,85,72) 在彩色屏上一个是绿一个是棕，
但灰度差只有 **1.5 个亮度级**——打印成黑白后，「定义」框与「物理史话」框
完全同色。8 类语义框因此退化为 8 个同灰度的同形盒子。

### 1.2 一次失败尝试（如实记录）

我最初手工定的新色板（`sem1..sem8` = 28,58,112 / 22,84,96 / …）
**实测最小间隔只有 1.0，比原稿的 1.5 还差**。手工估色无法保证明度均匀。
于是改为在 HLS 空间做数值搜索：给定 8 个等距灰度目标
（45, 57.1, 69.3, 81.4, 93.6, 105.7, 117.8, 130），
对每个语义色搜索满足该灰度的 RGB，误差 < 0.2 灰度级，最终间隔恒为 12.0–12.3。

> 这个弯路本身是结论：**「凭感觉配色」和「凭测量配色」的差距是 12 倍。**
> 建议作者采纳时也用脚本校验，而不是肉眼比对。

### 1.3 诚实的边界：调色**无法**解决色盲

实测 deuteranopia 模拟（Brettel 近似矩阵）下，新色板仍有 4 组色对距离 < 45：

```
定理 <-> 定义   d=37
定义 <-> 例题   d=37
例题 <-> 误区   d=34
推论 <-> 误区   d=24
```

**数量与原稿相同（4 组）。** 这不是配色失败，而是「只用颜色区分 8 个类别」
这条路径的物理上限——红绿色盲压缩了整个色相维度，任何 8 色方案都会撞墙。

**因此本方案的设计重心不是「找到更好的 8 个颜色」，而是让颜色不再是必需品**：
第 4 节的形状编码才是色觉友好性的真正保障。

## 2. 新色板（可直接替换）

```latex
% 灰度精确等距：45 / 57 / 69 / 81 / 93 / 106 / 118 / 130，间隔恒为 12.0
\definecolor{sem1}{RGB}{19, 44, 118}    % 定理  gray  45  深靛
\definecolor{sem2}{RGB}{15, 72, 92}     % 定义  gray  57  深青
\definecolor{sem3}{RGB}{25, 93, 64}     % 例题  gray  69  深绿
\definecolor{sem4}{RGB}{111, 78, 21}    % 推论  gray  81  赭石
\definecolor{sem5}{RGB}{214, 41, 47}    % 误区  gray  93  砖红
\definecolor{sem6}{RGB}{155, 65, 185}   % 洞见  gray 106  紫
\definecolor{sem7}{RGB}{99, 124, 136}   % 史话  gray 118  蓝灰
\definecolor{sem8}{RGB}{104, 161, 38}   % 提示  gray 130  橄榄

% 主色与正文色独立于语义色（原稿把 coverMid 同时用作正文标题色，耦合过紧）
\definecolor{inkBrand}{RGB}{32, 48, 92}      % 主色，对比白 11.2:1
\definecolor{inkBody}{RGB}{28, 28, 32}       % 正文近黑（不用纯黑，减少刺眼）
\definecolor{inkMuted}{RGB}{108, 112, 124}   % 次要信息，4.6:1
```

**相较原稿的取舍：**
- 去掉 `reviewblue`（与原 `thmblue` 灰度差仅 2，语义上也与「定理」重叠）——语义类型从 9 类收敛到 8 类。
- 未沿用原稿 `coverMid`(28,42,96) 作正文标题色：它与 `sem1` 灰度仅差 1，
  标题与「定理」框会糊在一起。新方案主色 `inkBrand` 与 `sem1` 明度分属不同层。

**已知未达标项（须作者决策）：** `sem8 提示` 对白对比度仅 3.13:1，
低于 WCAG AA 的 4.5:1。它只在**侧边条与图标**上使用，框内正文仍是近黑
（对比度 >18:1），因此不影响可读性；但若该色用于小字正文则需再压暗。
我选择保留亮度以维持阶梯的等距性——这是**「阶梯均匀」与「AA 达标」的取舍**，
建议作者按实际用途定夺。

## 3. 信息层级：用尺幅而非颜色建立秩序

原稿的层级问题：章标题（64pt 淡色章号）、节标题（Large 黑体）、色块标题（small 黑体）
三者的**视觉权重差距不够**，且节标题与色块标题都靠同一种「主色 + 黑体」表达。

新方案定义三层清晰的权重：

| 层级 | 手段 | 实测参数 |
|---|---|---|
| 章首页 | **全宽色带**（3.08cm 高）+ 58pt 章号 + 9pt letterspaced「CHAPTER」 | 色带占页高 10% |
| 节标题 | 左侧 **3pt 主色强调条** + Large 黑体 | 标题前 16pt / 后 7pt |
| 小节 | 无装饰，深色黑体 | 前 11pt / 后 5pt |
| 色块标题 | heiti\small + **几何图标** + 左侧 4pt 侧边条 | 前后 skip 9pt |

### 3.1 实测修正：章首页色带的两次返工

第一版把 58pt 章号与「CHAPTER」标签放在
`(2.4cm, -1.62cm)` 与 `(4.5cm, -1.05cm)`，实测两者**垂直位置几乎重合**
（章号 y=0.95–2.27cm，标签 y=0.93–1.13cm），视觉上挤在同一基线。

修正为标签在上、章号在下的**垂直堆叠**，并用 `anchor=south west` /
`anchor=north west` 明确锚点后重测：

```
色带 3.08cm 高；标签 y=0.93–1.13cm；章号 y=1.18–2.27cm；水平间距 1.39cm
```

两元素不再重叠，层次由「CHAPTER → 大号数字」自上而下展开。
**这正是「必须实际渲染测量」的价值**——这个碰撞在 .tex 源码里完全看不出来。

## 4. 色块设计：三重冗余编码（本方案的核心）

8 类语义框统一骨架，但叠加**三重**互相独立的识别通道：

| 通道 | 实现 | 失效条件 |
|---|---|---|
| ① 明度 | `sem1..sem8` 等距灰度 | 完全去色（缩略图、传真） |
| ② 形状 | 左侧 4pt **实心侧边条** | 分辨率极低 |
| ③ 图标 | 标题前 `\ding` 几何符号（□ ◆ ● ▲ ✦ ★ ▣ ◈） | 单色仍 100% 可辨 |
| ④（补充）线型 | 检查清单用**虚线**侧边条；公式卡用**双线**（west+north） | — |

统一性处理：所有框都是 `boxrule=0pt`（**去掉整框描边**）、
`borderline west` 侧边条、`arc=1.6pt` + `sharp corners=southwest`
（左上圆、右下直），形成一致的「页签」形态。
原稿的整框描边 + 四角统一切角在全彩下尚可，但去色后 8 个框完全同形。

### 4.1 亲自踩到的字体坑（与原稿缺陷同源）

我最初直接写 `■ ◆ ● ▲ ★ ✦ ▣ ◈`，编译立刻报
**19 处 `Missing character`——这些字形在 lmroman 中不存在**
（U+25A0 / 25C6 / 25CF / 25B2 / 2605 / 2726 / 25A3 / 25C8）。

这**与原稿 ①②③ 的缺陷是同一类错误**。我把它改走 `pifont` 的 dingbat
字体（`\ding{110..118}`）后归零。这条经验直接支撑对原稿的建议：
**任何非 ASCII 装饰字符在交付前都必须以 log 的 `Missing character` 计数验证**，
不能只看 PDF 预览（空白字形在预览里很容易被忽略）。

## 5. 正文可读性

| 参数 | 原稿 | 新方案 | 依据 |
|---|---|---|---|
| 行距 | 约 1.2（默认） | **1.32** | 11pt 中文下兼顾密度与呼吸感 |
| 段首缩进 | 0（用 `parskip=2.6pt` 分段） | **2em + parskip=0** | 中文排版惯例；西式段距套中文会让段落边界模糊 |
| 公式上/下留白 | 5pt | **7pt** | 公式与正文混杂处更易切分 |
| `\jot` | 2pt | 3pt | 多行公式间距 |
| 列表 `leftmargin` | 1.4em | 1.6em | 嵌套列表更清晰 |
| 表格 `tabcolsep` | 5pt | 6pt | 缓解原稿第 209 页单元格逐字换行 |

**字号取舍：** 样张用 11pt（原稿 12pt）。12pt 在 210 页规模下页数偏多，
且中文 12pt 配单倍行距偏紧。若作者希望保持 12pt，行距应同步提到 1.4。
**这是需要作者拍板的取舍，不是技术缺陷。**

## 6. 导航元素

### 6.1 页眉页脚
- 原稿：页眉左 `\itshape\leftmark`、右页码，**无页脚**，`footskip=1.0cm` 未使用（底部约 1cm 空带）。
- 新方案：页眉左黑体小节名（**去掉 itshape**——中文无真斜体，会触发合成倾斜）、
  右页码；**页脚放书名**（`\scriptsize` 中性色），兼顾散页归位；
  页眉下改用 `\leaders` 绘制的 0.6pt 短色规，比通栏细线更轻。
- 章首页 `plain` 页式已重定义，**带页码**（原稿章首页无页码）。

### 6.2 难度边注
原稿 `\difficulty` 的缺陷（t1 已实测）：宏内 `\hfill` 把 2pt 竖线顶到边注盒右沿，
墨迹达 20.62cm，**越出边注盒（20.50cm），影响 20 页**。

新方案改为**胶囊形色签**，`\raggedleft` + **保留 1.2mm 安全边距**，绝不越界：

```latex
\newcommand{\difficulty}[1]{%
  \marginnote{\raggedleft
    \tikz[baseline=(m.base)]{%
      \node[fill=diffMark!12, draw=diffMark!55, line width=0.4pt,
            rounded corners=4pt, inner xsep=4pt, inner ysep=1.6pt,
            text=diffMark, font=\scriptsize\heiti] (m) {#1};}%
    \hspace{1.2mm}}%
}
```
胶囊形态（圆角 + 淡底 + 细描边）比原稿的「竖线 + 方括号」更易在页边被扫读，
且**形状本身**就与正文区分，不依赖颜色。

### 6.3 交叉引用
统一封装 `\fref{}`（主色 + 粗体）与 `\cref`，避免原稿中链接色与正文标题色
同为 `coverMid` 导致「链接」与「标题」混淆。

## 7. 迁移成本与步骤

### 7.1 成本评估

| 工作项 | 改动范围 | 预估 |
|---|---|---|
| 替换色板定义 | 导言区 9 行 | 10 分钟 |
| 替换 8 类 `\newtcbtheorem` | 导言区 8 处 | 30 分钟 |
| 章/节 `titleformat` | 导言区 3 处 | 30 分钟 |
| 页眉页脚 + plain 页式 | 导言区 1 块 | 15 分钟 |
| `\difficulty` 重写 | 导言区 1 处 | 10 分钟 |
| 正文行距/缩进/间距 | 导言区 1 块 | 5 分钟 |
| **合计（导言区重构）** | **~120 行** | **约 2–3 小时** |
| 全稿视觉回归（210 页） | 通读 PDF | 约 3–4 小时 |

**关键判断：迁移成本很低。** 因为原稿的样式全部集中在导言区
（第 1–250 行左右），正文与 `ch*_supplement.tex` **几乎不需要改动**——
tcolorbox 环境名、`\difficulty` 命令名、`\chapter` / `\section` 结构全部保持不变。
这是原稿架构上的一个优点，应当在重构中保留。

**唯一的正文级改动**：`\cnum`/图标类宏若引入，需确认调用点。
本样张中未修改任何正文内容文件。

### 7.2 建议迁移步骤（低风险顺序）

1. **先换色板**（`sem1..sem8` + `inkBrand`），其余不动，编译并逐一核对 8 类框。
   此时黑白打印的语义区分度即已获得 8 倍改善。
2. **再加冗余编码**（侧边条 + 图标）——这一步才是色觉无障碍的真正落点。
3. **再改层级**（章色带 + 节强调条），对照样张第 3–4 页核对。
4. **最后动正文流量参数**（行距/缩进/间距），因为这会改变全书分页，
   需要整本重排并重新核对目录页码（原稿 210 页 → 预计 220–230 页）。
5. 全稿回归：`Missing character = 0`、`Overfull \hbox` 计数、
   逐页像素扫描右边界越界数（脚本见 t1 与 t7 的 `reviews_tmp/*.py`）。

### 7.3 需要作者决策的三点

1. **正文字号 11pt 还是 12pt**（影响页数与行距配比）。
2. **章首页是否采用全宽色带**（改动最"重"，也最能建立层级；若想更保守可退回 64pt 淡色章号，仅调整明度）。
3. **`sem8 提示` 的对比度取舍**：维持阶梯等距（3.13:1）还是压暗至 AA（破坏等距）。
