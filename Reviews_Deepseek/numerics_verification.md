### 3.2 物理正确性复核

**G.1（单粒子轨道）** ✅
- `B_mirror(r)` 满足 $\nabla\cdot\vect B=0$：$B_z=B_0(1+z^2/L^2)$，$B_r=-\tfrac12 r\,\partial_zB_z=-rB_0z/L^2$。我用散度公式核对：柱坐标下 $\nabla\cdot\vect B=\frac1r\partial_r(rB_r)+\partial_zB_z=\frac1r(-2rB_0z/L^2)+2B_0z/L^2=0$ ✅

- E×B 漂移结果 $v_E=E/B=10^3/1=1000$ m/s，与解析值一致。

**G.2（德拜屏蔽）** ⚠️ 可运行但与正文的物理口径需注意
- 球坐标泊松方程形式 `phi'' + (2/r) phi' = ...` 正确。
- 边界条件 $\phi(r_{\min})=q/(4\pi\eps_0r_{\min})$ 是**裸库仑势**，而非德拜势 $\frac{q}{4\pi\eps_0}\frac{e^{-r/\lambda_D}}{r}$。两者在 $r_{\min}=10^{-3}\lambda_D$ 处相对差约 $10^{-3}$（我算得 0.0999%），因此**不影响本算例结论**。
- 但 `bc` 中 `yb[0] = 0`（$\phi(r_{\max})=0$）在 $r_{\max}=15\lambda_D$ 处**物理上并不严格成立**：真实的线性德拜势在 $15\lambda_D$ 处仍有 $\sim e^{-15}\approx3\times10^{-7}$ 的相对残留（我算得 $\phi(r_{\max})/\phi(r_{\min})\approx2\times10^{-11}$，绝对量极小）。属数值处理上的合理近似。
- 解析解定标 `A = phi_rmin*r_min*exp(r_min/lam_D)` 与所设边界条件自洽。
- **结论**：代码可作为教学演示，但建议在注释中说明"$\phi(r_{\max})=0$ 是数值边界近似，非物理边界条件"，避免读者误以为是严格推导。

## 4. 附录 B 参数表一致性核查

发现 **1 条符号命名不一致**（数值本身正确）：

**B-1　$\ln\Lambda$ 的碰撞参数符号在附录 B 与第 8 章之间不一致**
- **定位**：附录 B `:4867`–`:4868`（$b_\pi$）vs 第 8 章 `:2571`、`:2604`（$b_0$）
- **问题**：
  - 第 8 章定义 $b_0=\dfrac{|q_1q_2|}{4\pi\eps_0 m_rv^2}$（$90^\circ$ 散射碰撞参数），并写 $\Lambda=\lambda_D/b_0$。
  - 附录 B 定义 $b_\pi=\dfrac{e^2}{4\pi\eps_0k_BT}$，并写 $\ln\Lambda=\ln(\lambda_D/b_\pi)$。
  - 二者**符号不同**：$b_\pi$ 用的是热能 $k_BT$ 作为能量标度，$b_0$ 用的是 $m_rv^2$。对热粒子 $m_rv^2\to2k_BT$，故 $b_\pi=2b_0$，相差因子 2。
- **复算证据**：
  ```
  b_pi / b_0 = 2.000000
  ln(lambda_D/b_pi) = 20.062119
  ln(lambda_D/b_0)  = 20.755266
  difference = ln 2 = 0.693147
  ```
- **重要澄清**：附录 B 的 $b_\pi$ **恰好**给出第 8 章所声明的 $\Lambda=3N_D$：
  ```
  (lambda_D/b_pi)/(3*N_D) = 1.00000000
  ```
  所以**两处的数值结果一致**，第 8 章在从 $b_0$ 推到 $3N_D$ 的过程中实际上已经做了 $m_rv^2\to2k_BT$ 的热平均替换（`:2604` 的等式链）。**这只是符号命名不统一，不是数值错误**，影响远小于 P2-1。
- **修复建议**：在附录 B 该行加注"$b_\pi$ 即第 8 章的 $b_0$ 取热平均后的形式（$m_rv^2\to2k_BT$）"，或统一改用同一符号。

其余附录 B 条目（$\lambda_D$、$\omega_{pe}$、$v_{te}$、$N_D$、$\Gamma$、$\omega_{ce}$、$v_A$、$\beta$、$R_m$）的公式与正文一致 ✅。

**数值口径问题（与 P2-1 同源）**：附录 B `:4870` Spitzer 电阻率行标"典型值 $\sim10^{-8}\ \Omega\cdot$m"，但第 8 章算例（10 keV）得到 $8.8\times10^{-10}$，相差约一个数量级，且该行未标温度条件。详见 `physics_ch07_12.md` 的 P2-2。
