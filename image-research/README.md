## 核实方法与复核脚本

- 候选来自 Wikimedia Commons，通过 MediaWiki API 的 `list=categorymembers` 与 `list=search` 枚举。
- 许可与作者取自 API `extmetadata` 的 `LicenseShortName` / `Artist`，分辨率取自 `imageinfo` 的 `width`/`height`，均非人工推断。
- 「直链验证」列为对 `upload.wikimedia.org` 直链实测的 HTTP 状态码结果（206 = 分段 GET 成功返回数据）。
- 关键坑：`upload.wikimedia.org` 对**不符合 Wikimedia User-Agent 政策**的客户端一律返回 HTTP 429，
  与请求频率无关。必须使用 `<客户端名>/<版本> (<联系方式>)` 形式的 UA 才能取到文件。
- 复核脚本：`tools/gen_table.py`（由 `tools/verified.json` 重新生成本文件）。
