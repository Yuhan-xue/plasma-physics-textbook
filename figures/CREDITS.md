## 采集与校验

- 检索与下载：用 Wikimedia Commons API 按概念检索，过滤许可与分辨率；
  下载回本地后等比缩放到长边 ≤ 1500 px，照片存为 JPEG（q88–q92），不做裁剪与调色。
- 入库检查（`check/figure_layout.py`）：每处插图必须文件存在、图环境内有 `\figsource` 署名、
  已在本表登记、单张不超过 1.5 MB，缺一项即判 FAIL。
- 版权口径：只取「公有领域 / CC0 / CC BY / CC BY-SA」；CC BY-NC-SA、付费许可与「保留所有权利」的来源一律不用。
