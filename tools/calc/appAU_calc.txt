==== AU.1 从信号到误差棒：一根棒子里的三笔账 ====
单点统计项 u_stat = 0.05（相对）
B 类系统项 u_sys = 0.02（相对，按均匀分布直接取半宽）

扩展不确定度 U = 2.0 u_c = 0.107703 -> 10.77033%（约 95%）
判据对照：U = 10.77033% -> 满足 15% 判据；超过 10% 判据 0.77033 个百分点
若要求 U <= 5%（k=2）: u_c <= 0.025, 统计项需 <= 0.015（现为 0.05）
  每点光子数需 x11.1111 -> 2222.22 个 -> 取整 2223 个

==== AU.2 两条腿：A 类统计、B 类系统、合成与扩展 ====

==== AU.4 最小二乘与卡方：把直线拟合进带误差的点 ====
x_i = i/(N-1), i=0..19；xbar = 0.5, S_xx = 1.84211
斜率不确定度 sigma_b = sigma_y/sqrt(S_xx) = 0.368394 counts/单位 x
截距不确定度 sigma_a = sigma_y sqrt(1/N + xbar^2/S_xx) = 0.215473 counts
相关系数 corr(a,b) = -xbar/sqrt(xbar^2 + S_xx/N) = -0.85485
自由度 dof = N - 2 = 18；chi2/dof 的固有散布 sigma = sqrt(2/dof) = 0.333333 -> 33.3333%
95% 区间（dof=18 附近）：chi2 小于 9.39 或大于 28.869 都说明模型/误差有问题

==== AU.7 蒙特卡洛、样本量的不确定度与三类陷阱 ====
N =   20：标准差本身的相对不确定度 1/sqrt(2(N-1)) = 16.22214%
N =  200：标准差本身的相对不确定度 1/sqrt(2(N-1)) = 5.01255%
N = 2000：标准差本身的相对不确定度 1/sqrt(2(N-1)) = 1.58153%
混叠：真实 f = 1300 Hz，采样 f_s = 1000 Hz -> 假峰 |f - f_s| = 300 Hz
  要避开混叠需 f_s >= 2 f = 2600 Hz（Nyquist）
分辨率合成：仪器 1 nm 与真实线宽 0.5 nm -> 观测 1.11803 nm（方和根）
  若直接反解真实线宽：sqrt(obs^2 - inst^2) = 0.5 nm（对 obs 的误差放大 2.2361 倍）
基线扣除：信号 100 counts、基线 1000 counts、各自 sigma = 10 -> 扣后 sigma = 14.1421（相对 14.1421%）
3 sigma 检测限：3 x 14.1421 counts = 42.4264 counts；若灵敏度 100 counts 对应 1e16 m^-3，则检测限 4.24264e+15 m^-3
