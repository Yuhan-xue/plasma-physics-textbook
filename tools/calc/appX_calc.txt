0. 工作点 D1
========================================================================
n_e = 1e+20 m^-3, T_e = 9.194 keV, B = 5.3 T, a = 2 m, R = 6.2 m
V = 832.2 m^3, Z_eff = 2, P_fus = 5.565e+08 W, P_alpha = 1.113e+08 W, W_th = 3.714e+08 J

========================================================================
1. 轫致辐射（光学薄，主要辐射损失）
========================================================================
P_br = 5.35e-37 * 2 * (1e+20)^2 * sqrt(9.194) = 32444 W/m^3 = 32.444 kW/m^3
全等离子体 P_BR = P_br * V = 2.7e+07 W = 27 MW
P_BR / P_alpha = 24.259%
P_BR / P_fus   = 4.8518%
T_e / (m_e c^2) = 0.017992；一阶相对论修正因子 1 + 2T/(m_e c^2) = 1.036
修正后 P_br = 33612 W/m^3（提高 3.598%），P_BR = 27.972 MW
平均光子能量量级 ~ T_e = 9194 eV；波长 = 1.3485e-10 m = 0.13485 nm

========================================================================
2. 回旋辐射：光学薄上限
========================================================================
f_ce = eB/(2 pi m_e) = 1.4836e+11 Hz = 148.36 GHz
磁能密度 u_B = B^2/(2 mu0) = 1.1177e+07 J/m^3
beta_perp^2 = 2T/(m_e c^2) = 0.035984
单电子 Larmor 功率 P_1 = (4/3) sigma_T c beta^2 u_B = 1.0695e-14 W
光学薄 P_cyc = n_e P_1 = 1.0695e+06 W/m^3 = 1.0695 MW/m^3
全等离子体 P_CYC(光学薄) = 8.9001e+08 W = 890.01 MW
P_CYC(光学薄) / P_BR = 32.963
P_CYC(光学薄) / P_fus = 1.5993  <-- 大于 1，物理上不可能

========================================================================
3. 回旋辐射：黑体（Rayleigh-Jeans）上限
========================================================================
第一壁面积 A = 4 pi^2 R a = 489.53 m^2
RJ 通量（按一个谐波带宽 ~ f_ce 估）F = 2 pi nu^3 kB T / c^2 = 336.28 W/m^2
P_CYC(黑体上限) = 1.6462e+05 W = 0.16462 MW
再吸收把光学薄上限压低 5406.4 倍
P_CYC(黑体上限) / P_BR = 0.60971%

========================================================================
4. 自由-自由吸收与光学深度（轫致辐射为什么逃得掉）
========================================================================
n_e = 1e+14 cm^-3, T = 1.0669e+08 K, h nu / kT = 6.6736e-08
alpha_ff = 1.4641e-08 cm^-1 = 1.4641e-06 m^-1
沿弦长 L = 2a = 4 m 的光学深度 tau_ff = 5.8564e-06
tau_ff << 1：轫致辐射光学薄，几乎全部逃逸
平均自由程 1/alpha_ff = 6.8301e+05 m（比装置尺寸大 1.7075e+05 倍）

========================================================================
5. 线辐射与辐射崩塌阈值（钨，L_W 取 10 keV 量级）
========================================================================
L_W = 1e-32 W m^3（声明：钨在 10 keV 的量级值）
n_W/n_e = 1e-05 -> n_W = 1e+15 m^-3
P_line = n_e n_W L_W = 1000 W/m^3 = 1 kW/m^3
全等离子体 P_LINE = 8.322e+05 W = 0.8322 MW
P_LINE / P_BR = 3.0822%
辐射崩塌阈值（P_LINE = P_alpha）：n_W* = 1.3374e+17 m^-3，f_W* = 0.13374%

========================================================================
6. 辐射在功率账里的位置
========================================================================
P_rad = P_BR + P_LINE = 27.832 MW
P_rad / P_fus = 5.0013%
自加热余量 P_alpha / P_rad = 3.999
辐射冷却时间 tau_rad = W_th / P_rad = 13.344 s
对照：附录 V 的电流猝灭时间 tau_CQ = 76.9074 ms
轫致辐射摊到第一壁：P_BR / A = 55155 W/m^2 = 55.155 kW/m^2
