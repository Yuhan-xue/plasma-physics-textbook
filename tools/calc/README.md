# tools/calc/ —— 书里每个数字的出处

这本教材正文里印出来的数值（工作点参数、阈值、裕度、练习题解答）不是抄来的，
而是由这里的脚本算出来的。每个专题附录对应一个脚本，文件名与附录字母一致：

    python tools/calc/appAE_calc.py      # 附录 AE（动理学与回旋动理学）的全部数值
    python tools/calc/appM_calc2.py      # 附录 M 的加热功率账

脚本只用 NumPy 与标准库，直接打印结果；同名的 `.txt` 是当时保存的输出记录，
方便对照书里印的数。要查某个数字是怎么来的，在附录「来源、分级与版权说明」里
找到脚本名，再打开对应文件即可。

正文不印代码，只印路径——想读代码请从本目录进入。
