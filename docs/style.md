# 文风规范：写给人读的教科书

**一句话：像一位有耐心的老师当面讲话，不像一份生成的报告。**

这本书的读者是一个人、一支笔、一台能算数的电脑。写作只有两个要求：
**说清楚**，**别啰嗦**。下面每一条都能被检查，不是审美偏好。

---

## 1. 硬指标（`check/ui_readability.py` F 类会量）

| 指标 | 目标 | 越界后果 |
|---|---|---|
| 句子长度 p90（正文） | ≤ 60 字 | > 60 字判 FAIL |
| 句子长度 p90（附录） | ≤ 75 字 | > 75 字判 FAIL |
| 段落长度 p90 | ≤ 200 字 | > 200 字告警 |
| 单句 | 不超过 100 字 | 计为超长句 |
| 单句内枚举 | 不超过 2 项 | ≥ 3 项且 > 80 字要改成列表 |

正文与附录分两套线：正文要连续读，句子短一档；附录里的「出处」是书名、
卷期、页码堆出来的长宾语，把它切碎只会更难查，所以放到 75 字。
两套线都由 `tools/style_lint.py` 量，正文远超时先改正文。

一句话只做一件事。要转折就断句，不要用逗号串起五个分句。

## 2. 禁用词表

**空转连接词**（删掉不影响意思，就删）：
值得注意的是、需要指出的是、不难发现、众所周知、毫无疑问、显而易见、
综上所述、总而言之、总的来说、换言之、简单来说、从某种意义上说、
事实上、实际上、与此同时、此外（连续出现时）、进一步地、更重要的是。

**自我表演**（读者不关心作者在做什么）：
本书将……、接下来我们……、让我们……、我们可以看到……、笔者认为、
需要注意的是本节……、这里不再赘述。

**假深刻**（说了等于没说）：
不仅……而且……、既……又……、在……方面、对于……而言、
起到了重要作用、具有重要的意义、为……奠定了基础、开启新篇章、
赋能、助力、抓手、闭环、生态、范式、维度（作"方面"解时）。

## 3. 该删的五类段落

1. **元叙述**：告诉读者"这一节要讲什么"的段落，如果紧跟着就是正文，删。
   节标题已经把话说完了。
2. **重复交代**：同一个事实在相邻两句里说两遍（先概括再展开），
   留信息量大的那句。
3. **过程旁白**：写作过程、版本、检查脚本怎么跑——这些属于
   `CHANGELOG.md` 与 `docs/`，不属于正文。
4. **结论复述**：节末把本节公式再讲一遍"由此可见……"。读者刚看完。
5. **对称排比**：为了好听凑出的三句同构短句。技术书不需要韵律。

## 4. 该保留的

- **具体数字与量级**：`10 keV`、`5 T`、`10²⁰ m⁻³` 是这本书的骨头；
- **一句一处的出处**：谁在哪本书哪一章讲的；
- **"先猜再看"与自测**：这是自学装置，不是装饰；
- **直白的第一人称复数**：讲推导时说"我们先……"没问题——这是老师在讲课，
  不是 AI 在总结。要删的是**空的**"我们"，不是所有"我们"。

## 5. 改写示例

**改前**（132 字，两处空转，一句总结）
> 值得注意的是，德拜屏蔽是一个非常重要的概念。事实上，它不仅解释了为什么等离子体
> 在宏观上呈现电中性，而且在等离子体诊断、鞘层物理等多个方面都具有重要的意义。
> 综上所述，理解德拜屏蔽对于后续章节的学习具有重要的价值。

**改后**（41 字）
> 德拜屏蔽解释了等离子体为什么在宏观上呈电中性：任何外来电荷都会被
> 一个半径约 $\lambda_D$ 的电子云包住，势场在几个 $\lambda_D$ 内衰减到零。

**改前**（三句同构排比）
> 加热靠欧姆，欧姆在中温失效；加热靠束流，束流在深处失效；加热靠射频，射频在边缘失效。

**改后**（一句说清规律）
> 温度越高，欧姆加热越无效：$\eta_\parallel\propto T_e^{-3/2}$。所以中温以上必须换束流或射频。

## 6. 不许动的

改写只碰**散文**。以下一律不动，动了就是错：

- 公式、符号、单位、数值、量级、表格数字；
- `\label{}`、`\ref{}`、`\cite{}`、`\input{}`、环境名与参数；
- 图注里的物理结论（可以压缩措辞，不许改结论）；
- 交叉引用的措辞（"见 \S M.2"、"配套手册 J"）。

改完必须能让 `check/full_check.py` 与 `check/consistency_audit.py` 仍然全过。

## 7. 自检

```powershell
python -X utf8 tools/style_lint.py            # 本仓库的文风体检（套话/破折号/句长）
python -X utf8 tools/style_lint.py --rev HEAD # 与改前对比
python -X utf8 check/ui_readability.py         # 句长 / 段长 / 枚举 / 对比度
python -X utf8 check/consistency_audit.py      # 术语、符号、速查卡
python -X utf8 check/full_check.py --no-compile   # 结构、标签、引用、数字口径
```
