## 第 1 轮发现（13 项：P1×1、P2×10、P3×2）

最重的一项是第 9 章对称双流模型：正文、例题与速查卡用了与已声明总密度不一致的解析根，
导致稳定阈值、最大增长率和数值答案成组出错。第 12 章的诊断定义、图形遮挡与数值验证流程
也有可复现问题。逐条编号（PP-Cxx 内容 / PP-Uxx 阅读与 UI / PP-Wxx 验证流程）见 git 历史。

## 这些评审改变了什么

- **图形**：图 9.1 注释压连线、图 9.2 分类节点重叠 → 促成 `check/figure_layout.py`：
  直接量 PDF 几何，查节点交叠、标签被框裁切、文字叠字、线条穿字、越出版心。
- **验证流程**：旧编译检查把"任意单个缺字"和"单次严重溢出"判 PASS → 改为缺字逐字列出、
  Overfull 超阈值即报，并加了 `fixtures/` 负例自测。
- **数值**：附录 G.2 把求解器 `status=1` 当成收敛 → 示例脚本改为显式检查 `success` 与残差。
- **内容**：对称双流、Buneman 增长率、EEPF 定义、斜入射反射条件等成组修正，
  并统一了口径（同一量全书一个值）。

## 评审怎么跑

```powershell
python -X utf8 check/full_check.py            # 结构 / 内容 / 编译 / PDF / 文档一致性
python -X utf8 check/ui_readability.py        # 句长段长 / 枚举 / 颜色对比度 / 版式
python -X utf8 check/consistency_audit.py     # 术语 / 符号 / 速查卡 / 附录结构
python -X utf8 check/figure_layout.py         # 图形几何
python -X utf8 check/pdf_outline.py           # 书签 / 目录 / 交叉引用
```
