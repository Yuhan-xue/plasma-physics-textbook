# 全书配色与配图规范

**一句话：深蓝打底，金色点睛；低饱和、低明度、克制用色。**

这本书讲的是等离子体——暗处的高温发光体。所以视觉基调取"深空藏青 + 曦金"：
深蓝给庄严与纵深，金色只给能量、关键和结论。全书正文、盒子、TikZ 自画图、
`docs/` 页面与 `docs/overview.png` 一律遵守本规范。

> 颜色不是装饰。每一处上色都要回答一个问题：**它在告诉读者什么？**
> 答不上来就改回墨蓝或灰。

---

## 1. 色板

对比度一列是"该色文字印在白纸上"的 WCAG 比值。**正文与标签文字必须 ≥ 4.5。**

| 语义 | LaTeX 名 | HEX | RGB | 白底对比度 | 用法 |
|---|---|---|---|---|---|
| 墨蓝 | `figInk` | `#12203A` | 18,32,58 | 16.6 | 坐标轴、图内标签、正文强调色 |
| 深藏青 | `figNavy` | `#1B2E52` | 27,46,82 | 13.7 | 主色：封面、章标题、定理框 |
| 钢蓝 | `figBlue` | `#2F5286` | 47,82,134 | 8.9 | 离子、慢粒子、背景、次主色 |
| 雾蓝 | `figSky` | `#6C86AE` | 108,134,174 | 3.7 | 浅填充、次要曲线，**不作文字** |
| 深青 | `figGreen` | `#2A7373` | 42,115,115 | 5.5 | 磁场、磁力线、提示框 |
| 亮金 | `figGold`／`figOrange` | `#C2A14D` | 194,161,77 | 2.5 | 电子、高能粒子、关键路径，**只作线与填充** |
| 暗金 | `figAmber`／`figGoldDeep` | `#8A6520` | 138,101,32 | 5.3 | 金色**文字**、金色边框、警示框 |
| 赭红 | `figVerm` | `#9C443A` | 156,68,58 | 6.4 | 损失、阈值、不稳定性、洞见框 |
| 暗紫 | `figPurple` | `#5F4066` | 95,64,102 | 8.7 | 第三类分类、例题框 |
| 褐金 | `historybrown` | `#6E5638` | 110,86,56 | 6.9 | 物理史话框 |
| 中性灰 | `figGray` | `#6B7280` | 107,114,128 | 4.8 | 辅助虚线、图注小字、图片来源行 |
| 纸白 | `figPaper` | `#F6F2E7` | 246,242,231 | — | 浅底填充（替代纯白） |

**金的两个档必须分清**：`figGold` 是"发光的金"，只用于线条、色块、填充；
`figAmber` 是"印在纸上的金"，用于文字与边框。把 `figGold` 当文字用，
在白纸上只有 2.5:1，读不清——这是本书最容易犯的错。

## 2. 用色比例

- **60% 深蓝系**（`figInk`／`figNavy`／`figBlue`）：骨架、文字、坐标、主要曲线
- **30% 金系**（`figGold`／`figAmber`）：能量流向、关键路径、结论、强调
- **10% 其它**（`figGreen`／`figVerm`／`figPurple`／`figGray`）：语义必需时才出现

一张图里超过四种色相，通常说明这张图想讲的事不止一件——拆图，不要加色。

## 3. 图内语义映射（同一物理量全书同色）

| 物理量 | 颜色 | 配套 |
|---|---|---|
| 电子、快粒子、高热 | 亮金 `figGold` | 实线 1.2pt |
| 离子、慢粒子、背景 | 钢蓝 `figBlue` | 实线 1.2pt |
| 磁场、磁力线、线圈 | 深青 `figGreen` | 实线 1.2pt + 箭头 |
| 阈值、判据、边界 | 赭红 `figVerm` | 虚线 0.8pt |
| 辅助线、包络、渐近 | 中性灰 `figGray` | 虚线 0.6pt |
| 区域填充 | 同色 `!10`～`!14` | 同色 0.8pt 边 |
| 结论、关键路径 | 亮金 + 加粗 | — |

## 4. 版面与尺寸

书的版心宽 **17.30 cm**。图不是越大越好，**能把事说清就不必再大**。

| 类型 | 上限 | 说明 |
|---|---|---|
| 流程图、路径图、分类树 | 0.86\textwidth | 节点留白够就行，别铺满整页 |
| 坐标图、剖面图 | 0.78\textwidth | 高度不超过 8 cm |
| 竖幅照片 | 高度上限 9 cm | 按高度定尺，别按宽度 |
| 横幅照片 | 0.72～0.78\textwidth | 整幅满宽只在开篇大图用 |

字号：图内主标签 `\small`，次标签与刻度 `\footnotesize`，**全书禁用 `\tiny`**。
线宽：坐标轴 0.9pt、数据曲线 1.2pt、辅助虚线 0.6pt、箭头统一 `Stealth`。

## 5. 标签永不压线、永不叠字

1. 标签靠近曲线时，加 `fill=white, inner sep=1.5pt` 光环；
2. 标签放不进色块（留不出约 3 mm 边）就移到块外，用 `figlead` 引线点指；
3. 两个标签的包围盒不许相交，文字不许被框边裁切；
4. 图例一律放绘图区外（下方或右侧），带线型样本；
5. 图注首句点题，一句话说清这张图在讲什么。

## 6. 语义盒（tcolorbox）

九种盒子按"蓝为主、金为辅"分配，标题栏白字与底色的对比度全部 ≥ 4.5:1
（由 `check/ui_readability.py` 的 G 类检查强制）：

定理=深藏青 · 定义=钢蓝 · 推论=暗金 · 例题=暗紫 · 物理洞见=赭红 ·
常见误区=暗金（标题栏加深）· 物理史话=褐金 · 本节要点=雾蓝 · 学习提示=深青

## 7. UI 与文档

- `README.md`、`docs/*.md` 里的图用同一套底色；标注性色块一律用 `#1B2E52` 底 + `#C2A14D` 字；
- `docs/overview.png` 由 `tools/overview_fig.py` 生成，配色直接取本表；
- 图册缩略图统一 230 px 宽、白底、1 px `#E5E0D2` 描边；
- 网页/编辑器预览不必上色，颜色规范只约束"会印出来的东西"。

## 8. LaTeX 落地位置

全书颜色只在 `src/plasma_physics_textbook_v2.tex` 导言区定义一处
（约第 54–245 行），**不许在正文文件里临时 `\definecolor`**。
新增颜色要同时在本文件登记语义与对比度。

## 9. 禁则

- ✗ 亮金当文字；✗ 纯黑 `#000`；✗ 高饱和纯色（`blue`／`red`／`green` 原色）；
- ✗ 彩虹渐变、发光阴影、3D 立体感；✗ 一张图里五种以上色相；
- ✗ 用颜色作为**唯一**区分手段（黑白打印必须仍可分辨：靠线型、形状、标注）。

## 10. 怎么查

```powershell
python -X utf8 check/ui_readability.py     # G 类：颜色对比度、盒子嵌套、边注溢出
python -X utf8 check/figure_layout.py      # P/Q 类：节点交叠、标签被裁、叠字、越出版心
python -X utf8 tools/render_figures.py --all   # 逐张出图，人眼复核
```
