# 等离子体物理自学教材

> **Plasma Physics: A Self-Study Textbook**  
> 一本面向自学者、兼顾物理图像与数学严谨性的中文等离子体物理入门教材。

---

## 项目简介

本项目是《等离子体物理自学教材》的完整 LaTeX 源码仓库。教材共 **239 页**，涵盖 12 章正文 + 11 附录，系统介绍从单粒子运动到聚变约束、从低温工业等离子体到实验诊断的核心内容。

教材定位：**让有微积分和电磁学基础的读者，无需导师即可系统入门等离子体物理。**

## 编译指南

### 环境要求

- **OS**：Windows / Linux / macOS
- **TeX 发行版**：TeX Live 2024+（推荐）或 MiKTeX
- **编译引擎**：XeLaTeX（必需，用于中文支持）
- **必要宏包**：`ctex`, `amsmath`, `tikz`, `pgfplots`, `tcolorbox`, `hyperref`, `cleveref`, `siunitx`, `booktabs`, `enumitem`, `fancyhdr`, `titlesec`, `epigraph`, `makeidx`

### 编译命令

```bash
cd src/
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex  # 第二遍解析交叉引用
```

> 由于使用了 `tcolorbox`、`hyperref` 和 `cleveref`，建议编译 **两遍** 以确保所有引用和目录正确解析。

### 已知限制

- **PDF 书签**：章节标题中含数学符号时，`	exorpdfstring` 已处理大部分情况，但可能有少量警告，不影响编译。
- **Overfull/Underfull hbox**：部分公式行和表格存在轻微溢出，属排版优化空间，不影响阅读。

## 质量检查

本仓库把「本书是否正确、是否好读」写成可复现的脚本，而不是依赖人工翻检。
六套检查均以 **FAIL 0** 为准入线（退出码非 0 即代表有必须处理的问题）：

```bash
python check/full_check.py         # 五类 32 项：结构 / 内容 / 编译 / PDF / 文档一致性
python check/ui_readability.py     # 两类 35 项：可读性 / 版式（UI）
python check/consistency_audit.py  # 四类 14 项：术语 / 符号 / 附录 / 标签一致性
python check/physics_regression.py # 三类 122 项：物理数值复核 / 表述断言 / 附录编号（纯标准库）
python check/figure_layout.py      # 图形版式 13 项：节点交叠 / 裁切 / 跨框 / 版心 / 叠字（需 PyMuPDF）
python check/pdf_outline.py        # 目录/书签 11 项：书签页码与印刷目录对齐 / 附录 F 指针（需 PyMuPDF）
```

- `full_check.py` 查**对不对**：悬空交叉引用、标签唯一性、盒子标题重复、
  章节编号一致性、编译错误与警告、PDF 页数与元数据、README/正文数字对齐。
- `ui_readability.py` 查**好不好读、好不好看**：正文句长与段长分布、
  超长句段、单句内埋藏的枚举、标题层级跳级、连续公式墙、
  **语义盒标题缺失**、**颜色对比度（按 WCAG 公式实算）**、盒子嵌套、
  浮动体与引用距离、边注溢出。
- `consistency_audit.py` 查**前后是否自洽**：术语变体（朗道/Landau、玻姆/Bohm）、
  速查卡公式符号是否都在「符号说明」里、附录 H 符号总表是否覆盖全书通用符号
  且每条都在正文出现过、附录章编号连续与挂载顺序、`README` 与正文的页数/附录数对齐。
- `physics_regression.py` 查**算得对不对**：把本轮修掉的每个数值都独立复算一遍——
  双流 $|ku|=2\omega_{pe}$ 与 $\gamma_{\max}=\omega_{pe}/\sqrt8$、Buneman 的 $\mu^{1/3}$ 标度与复根残差、
  $\int\delta'(v)/(v-c)\diff v=+1/c^2$、Salpeter 的 $\alpha$ 与阈值条件、斜入射 $\omega=\omega_{pe}/\cos\theta_0$、
  Druyvesteyn 往返反演——并断言源码里必须出现正确表述、不得再出现已修正的错误表述。
  v1.8.0 起新增 P 类 9 项，专门守新增的附录：附录 I/K 的 26 个物理量（德拜长度、损失锥、回旋半径、
  Alfvén 速度、Landau 阻尼率、Spitzer 电阻率、玻姆判据与鞘厚、Sweet–Parker 重联率）全部由常数独立复算后
  再回文找「印出来的那个数」，容差 1%–5%；附录 J 的逐章对照表必须覆盖第 1–12 章、每行 5 列、
  Chen ≤10 章 / Fitzpatrick ≤9 章（防幻章）、每行至少一个外文定位；附录 I 的 8 条 DOI 必须格式合法且不重复；
  三个新附录必须挂在主文件上、字母连续到 K、每个至少 4 小节。
- `figure_layout.py` 查**图有没有画坏**：直接读 PDF 里的填充矩形与文字包围盒，
  检查图 9.1／9.2 的节点框两两交叠、标签被框边裁切、一块文字跨两个框、节点越出版心；
  对没有节点框的示意图（图 9.3）改查**文字互相压盖**与**彩色箭头/连线穿过文字**
  （这两条规则正是目视第 114 页时发现问题后补上的）。
- `pdf_outline.py` 查**导航是否真的对得上**：书签页码是否落在 `[1, 页数]` 且单调不减、
  220 条印刷目录与 220 条书签是否按文档顺序一一对应（含重名条目，如 9 处「习题精选」）、
  目录链接目标页与书签页码是否一致、附录 F 的 35 个 `\S\ref` 指针显示的节号是否与
  `.aux` 里该 label 的真实节号一致、附录 F 区内链接数是否与正文引用数吻合。
  印刷目录的页跨度**动态探测**（自第 2 页起、连续「链接数 ≥12」的最长前缀）：
  附录增补后目录从 7 页涨到 8 页，写死常量会让「目录链接数 == 书签数」这条不变量假 FAIL。

`full_check.py` 与 `ui_readability.py` 会先剥离 LaTeX 注释与行间公式再统计——否则公式会被误判成超长句子。
`ui_readability.py` 另将「本章要点回顾」这类结构化小结**单独统计**：
其条目本就密集（全书 57 条无一使用嵌套列表），不该套用正文散文的句长阈值。

`check/fixtures/` 是各套判定的**可证伪夹具**：它们故意在源码、合成 PDF 或 PDF 书签里植入缺陷
（假缺字 α、200 pt 溢出、例题数值回退、节点框交叠、图形消失、两块文字叠在一起、
书签被改名/乱序/清空、附录 G.2 印刷输出被篡改……），
确认对应套件确实报 FAIL、恢复后确实回到 FAIL 0——
否则「检查通过」有可能只是检查失效：

```bash
python check/fixtures/gate_compile_log.py       # 合成编译日志，验 full_check / ui_readability 的判定
python check/fixtures/gate_physics_negative.py  # 植入 6 处数值回退（含附录 J/K），验 physics_regression 会报错
python check/fixtures/gate_figure_layout.py     # 合成 5 张 PDF，验 figure_layout 会报错（需 PyMuPDF）
python check/fixtures/gate_pdf_outline.py       # 篡改书签（改名/乱序/清空），验 pdf_outline 会报错（需 PyMuPDF）
python check/fixtures/gate_g2_listing.py        # 实跑附录 G.2 清单并逐行比对印刷输出（需 NumPy/SciPy/Matplotlib）
```

## 三条学习路线

教材支持非线性阅读，根据你的背景选择路线：

### 路线 A：零基础工科/微电子方向
> 目标：理解半导体刻蚀、镀膜、低温放电中的等离子体物理

必读：第 1 → 2 → 3（跳过高阶漂移）→ 4（仅 §4.1-4.3）→ 8 → **11 → 12**  
跳过：第 5、7、9、10 章

### 路线 B：聚变/空间物理方向
> 目标：系统掌握等离子体物理，为研究生课程或科研打基础

全读：第 1-10 章  
选修：第 11 章（若涉及偏滤器、壁处理）  
必读：第 12 章（诊断是聚变实验的核心）

### 路线 C：理论/仿真科研向
> 目标：熟悉推导技巧和数值工具，进入理论或计算等离子体物理研究

全书精读（含所有 ★★★ 挑战内容）  
数学补充：附录 A（矢量与张量公式汇总）、附录 C（省略的中间数学步骤）  
仿真拓展：附录 G（Python 仿真：单粒子轨道、德拜屏蔽、朗缪尔波色散）  
随身查阅：附录 H（37 条通用符号与算符 + 128 条物理量符号 + 136 条术语中英对照）  
节奏与复习：附录 I（12 周节奏模板、间隔重复与自测设计）  
横向对照：附录 J（同一主题在 Chen / Fitzpatrick 的哪一章讲得更细）

## 技术特色

### 排版设计
- **12pt book 类**：单面排版（`oneside`），A4 纸张，适合屏幕阅读
- **彩色定理环境**：`tcolorbox` 实现的定理/定义/例题/物理洞见/常见误区/历史盒子
- **难度边注**：`\difficulty{基础/提高/挑战}` 红色边注标识
- **跨章节串联**：15 处“参见第 X 章”提示，帮助建立知识网络
- **核心公式编号**：关键定义和定理公式统一编号，方便引用

### 内容组织
- **前置依赖提示**：每章开篇标注直接/间接依赖章节
- **自学检查清单**：每章末尾的绿色 checklist，含 5-8 项自检条目
- **历史背景穿插**：朗缪尔、阿尔芬、罗森布鲁斯等物理学家的故事
- **工业案例**：第 11 章 ICP 刻蚀侧壁倾斜、PECVD 沉积速率突降等真实故障诊断
- **Python 仿真**：附录提供可直接运行的代码
