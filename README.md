# 等离子体物理自学教材

> **Plasma Physics: A Self-Study Textbook**  
> 一本面向自学者、兼顾物理图像与数学严谨性的中文等离子体物理入门教材。

---

## 项目简介

本项目是《等离子体物理自学教材》的完整 LaTeX 源码仓库。教材共 **233 页**，涵盖 12 章正文 + 7 附录，系统介绍从单粒子运动到聚变约束、从低温工业等离子体到实验诊断的核心内容。

教材定位：**让有微积分和电磁学基础的读者，无需导师即可系统入门等离子体物理。**

## 编译指南

### 环境要求

- **OS**：Windows / Linux / macOS
- **TeX 发行版**：TeX Live 2024+（推荐）或 MiKTeX
- **编译引擎**：XeLaTeX（必需，用于中文支持）
- **必要宏包**：`ctex`, `amsmath`, `tikz`, `pgfplots`, `tcolorbox`, `hyperref`, `cleveref`, `siunitx`, `booktabs`, `enumitem`, `fancyhdr`, `titlesec`, `epigraph`, `makeidx`

### 编译命令

```bash
cd src/
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex  # 第二遍解析交叉引用
```

> 由于使用了 `tcolorbox`、`hyperref` 和 `cleveref`，建议编译 **两遍** 以确保所有引用和目录正确解析。

### 已知限制

- **PDF 书签**：章节标题中含数学符号时，`	exorpdfstring` 已处理大部分情况，但可能有少量警告，不影响编译。
- **Overfull/Underfull hbox**：部分公式行和表格存在轻微溢出，属排版优化空间，不影响阅读。

## 三条学习路线

教材支持非线性阅读，根据你的背景选择路线：

### 路线 A：零基础工科/微电子方向
> 目标：理解半导体刻蚀、镀膜、低温放电中的等离子体物理

必读：第 1 → 2 → 3（跳过高阶漂移）→ 4（仅 §4.1-4.3）→ 8 → **11 → 12**  
跳过：第 5、7、9、10 章

### 路线 B：聚变/空间物理方向
> 目标：系统掌握等离子体物理，为研究生课程或科研打基础

全读：第 1-10 章  
选修：第 11 章（若涉及偏滤器、壁处理）  
必读：第 12 章（诊断是聚变实验的核心）

### 路线 C：理论/仿真科研向
> 目标：熟悉推导技巧和数值工具，进入理论或计算等离子体物理研究

全书精读（含所有 ★★★ 挑战内容）  
数学补充：附录 A（复变函数）、附录 B（变分法）  
仿真拓展：附录 C（Python：单粒子轨道、PIC、双流体模拟）

## 技术特色

### 排版设计
- **12pt book 类**：单面排版（`oneside`），A4 纸张，适合屏幕阅读
- **彩色定理环境**：`tcolorbox` 实现的定理/定义/例题/物理洞见/常见误区/历史盒子
- **难度边注**：`	extbackslash difficulty{基础/提高/挑战}` 红色边注标识
- **跨章节串联**：21 处“参见第 X 章”提示，帮助建立知识网络
- **核心公式编号**：关键定义和定理公式统一编号，方便引用

### 内容组织
- **前置依赖提示**：每章开篇标注直接/间接依赖章节
- **自学检查清单**：每章末尾的绿色 checklist，含 5-8 项自检条目
- **历史背景穿插**：朗缪尔、阿尔芬、罗森布鲁斯等物理学家的故事
- **工业案例**：第 11 章 ICP 刻蚀侧壁倾斜、PECVD 沉积速率突降等真实故障诊断
- **Python 仿真**：附录提供可直接运行的代码
