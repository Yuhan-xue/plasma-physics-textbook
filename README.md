# 等离子体物理自学教材

一本写给自学者看的等离子体物理教材：从德拜屏蔽讲到聚变堆工程，12 章正文 + 48 个附录（另有一册配套手册）。
每个公式配量纲自检，每道例题配答案，关键数字都能自己动手复算一遍。

![托卡马克真空室内部：磁约束聚变要面对的容器](figures/tokamak_interior.jpg)

教材共 **612 页**，涵盖 12 章正文 + 48 附录，内容从单粒子运动一直走到聚变堆系统集成，
并在每一章里都放了自学需要的东西：核心目标、前置依赖、"先猜再看"、例题与答案、
随堂自测、估算练习。写作目标是**一个人、一支笔、一台能算数的电脑就能读完**。

## 怎么读这本书

**三条路线，按你的目标选一条**

- **路线 A（零基础 / 工科 · 微电子）**：第 1–2 章打底 → 第 3–6 章看物理图像 → 第 11 章进工艺 → 附录 P、Q 看应用与测量。
- **路线 B（聚变 / 空间物理）**：第 2–5 章 → 第 10 章 → 附录 M、N、S、U、Z（聚变主线）；或附录 AB（空间等离子体）。
- **路线 C（理论 / 仿真科研）**：第 4–9 章 → 附录 AC、AE、AF（数值与动理学），配合附录 G 的三个仿真脚本。

**每一章里都有这些装置**

| 装置 | 干什么用 |
|------|----------|
| 核心目标 / 前置依赖 | 开读前先知道自己该会什么、读完能做什么 |
| 先猜再看 | 先写下你的估计，再看答案——猜错的地方才是要读的地方 |
| 例题 + 答案 | 例题紧跟可核对的解答，不是"留给读者" |
| 随堂自测 | 每节末尾两三个问题，答案就在后面 |
| 估算练习 | 六道一组的量级估算，练"不看公式也能报出数" |
| 量纲自检 | 每个关键公式后检查量纲对不对 |
| 公式卡 / 概念图 | 一章结束时的速查卡与结构图 |
| 附录 I | 学习策略手册：三遍读法、间隔复习、费曼技巧、论文三遍法（在配套手册里） |

## 编译

**环境**：TeX Live 2024+ 或 MiKTeX；必须用 **XeLaTeX**（中文排版）。
主要宏包：ctex、amsmath、tikz、pgfplots、tcolorbox、hyperref、cleveref、siunitx、booktabs、enumitem、fancyhdr、titlesec、epigraph、makeidx。

```bash
cd src
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex   # 第二遍生成目录与交叉引用
```

**已知限制**：少量公式行与宽表格会有轻微 overfull 警告（不影响阅读）；
书签生成时有几条 `\texorpdfstring` 提示；PDF 约 25 MB，首次编译需几分钟。
PDF 的书签里有 27 条（约 4.5%，多为刚好另起一页的小节）比印刷页码早一页——印刷目录的页码是对的，
点书签会先落到标题的前一页；同因使附录 F 的 7 条跨章链接差一页。这两项已核实为 hyperref 与标题样式的锚点机制，
不影响正文阅读。

## 质量检查

仓库自带一套检查脚本，改动后可以自己跑一遍：

```bash
python check/full_check.py          # 结构 / 内容 / 编译 / PDF / 一致性 / 自学闭环
python check/physics_regression.py  # 重新计算书中印出的数字，核对是否一致
```
