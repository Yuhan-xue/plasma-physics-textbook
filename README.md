> **Plasma Physics: A Self-Study Textbook**  
> 一本面向自学者、兼顾物理图像与数学严谨性的中文等离子体物理入门教材。

---

## 项目简介

本项目是《等离子体物理自学教材》的完整 LaTeX 源码仓库。教材共 **313 页**，涵盖 12 章正文 + 19 附录，系统介绍从单粒子运动到聚变约束、从低温工业等离子体到实验诊断的核心内容。

教材定位：**让有微积分和电磁学基础的读者，无需导师即可系统入门等离子体物理。**

## 编译指南

### 环境要求

- **OS**：Windows / Linux / macOS
- **TeX 发行版**：TeX Live 2024+（推荐）或 MiKTeX
- **编译引擎**：XeLaTeX（必需，用于中文支持）
- **必要宏包**：`ctex`, `amsmath`, `tikz`, `pgfplots`, `tcolorbox`, `hyperref`, `cleveref`, `siunitx`, `booktabs`, `enumitem`, `fancyhdr`, `titlesec`, `epigraph`, `makeidx`

### 编译命令

```bash
cd src/
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex
xelatex -interaction=nonstopmode plasma_physics_textbook_v2.tex  # 第二遍解析交叉引用
```

> 由于使用了 `tcolorbox`、`hyperref` 和 `cleveref`，建议编译 **两遍** 以确保所有引用和目录正确解析。

### 已知限制

- **PDF 书签**：章节标题中含数学符号时，`	exorpdfstring` 已处理大部分情况，但可能有少量警告，不影响编译。
- **Overfull/Underfull hbox**：部分公式行和表格存在轻微溢出，属排版优化空间，不影响阅读。

## 质量检查

本仓库把「本书是否正确、是否好读」写成可复现的脚本，而不是依赖人工翻检。
六套检查均以 **FAIL 0** 为准入线（退出码非 0 即代表有必须处理的问题）：

```bash
python check/full_check.py         # 五类 35 项：结构 / 内容 / 编译 / PDF / 文档一致性
python check/ui_readability.py     # 两类 52 项：可读性 / 版式（UI）
python check/consistency_audit.py  # 四类 15 项：术语 / 符号 / 附录 / 标签一致性
python check/physics_regression.py # 四类 520 项：物理数值复核 / 结论口径 / 交叉一致性 / 新增附录（纯标准库）
python check/figure_layout.py      # 图形版式 13 项：节点交叠 / 裁切 / 跨框 / 版心 / 叠字（需 PyMuPDF）
python check/pdf_outline.py        # 目录/书签 11 项：书签页码与印刷目录对齐 / 附录 F 指针（需 PyMuPDF）
```

- `full_check.py` 查**对不对**：悬空交叉引用、标签唯一性、盒子标题重复、
  章节编号一致性、编译错误与警告、PDF 页数与元数据、README/正文数字对齐。
- `ui_readability.py` 查**好不好读、好不好看**：正文句长与段长分布、
  超长句段、单句内埋藏的枚举、标题层级跳级、连续公式墙、
  **语义盒标题缺失**、**颜色对比度（按 WCAG 公式实算）**、盒子嵌套、
  浮动体与引用距离、边注溢出。
- `consistency_audit.py` 查**前后是否自洽**：术语变体（朗道/Landau、玻姆/Bohm）、
  速查卡公式符号是否都在「符号说明」里、附录 H 符号总表是否覆盖全书通用符号
  且每条都在正文出现过、附录章编号连续与挂载顺序、`README` 与正文的页数/附录数对齐。
- `physics_regression.py` 查**算得对不对**：把本轮修掉的每个数值都独立复算一遍——
  双流 $|ku|=2\omega_{pe}$ 与 $\gamma_{\max}=\omega_{pe}/\sqrt8$、Buneman 的 $\mu^{1/3}$ 标度与复根残差、
  $\int\delta'(v)/(v-c)\diff v=+1/c^2$、Salpeter 的 $\alpha$ 与阈值条件、斜入射 $\omega=\omega_{pe}/\cos\theta_0$、
  Druyvesteyn 往返反演——并断言源码里必须出现正确表述、不得再出现已修正的错误表述。
  v1.8.0 起新增 P 类，专门守新增的附录：附录 I/K 的物理量（德拜长度、损失锥、回旋半径、
  Alfvén 速度、Landau 阻尼率、Spitzer 电阻率、玻姆判据与鞘厚、Sweet–Parker 重联率）全部由常数独立复算后
  再回文找「印出来的那个数」；附录 J 的逐章对照表必须覆盖第 1–12 章、每行 5 列、
  Chen ≤10 章 / Fitzpatrick ≤9 章（防幻章）、每行至少一个外文定位；附录 I 的 8 条 DOI 必须格式合法且不重复；
  四个新附录必须挂在主文件上、字母连续到 L、每个至少 4 小节；v1.10.0 起该期望延伸到 M、v1.11.0 延伸到 N、v1.12.0 延伸到 O
  （`APP_FILES` 增一条即自动扩展，字母序列、`\appchapter` 与 `\input` 紧邻、被 input 文件内无 `\appchapter`、
  小节数 ≥4 全部随之判定）。v1.13.0 延伸到 P、v1.14.0 延伸到 Q、v1.15.0 延伸到 R、v1.16.0 延伸到 S。
  **v1.9.0 起新增附录 L 题库守卫**：12 章 × 6 题的结构（每题都有「答案」）、每章 2 概念 + 2 推导 + 2 估算的
